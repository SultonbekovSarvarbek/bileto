# Bileto — перепродажа билетов (React Native / Expo)

Мобильное приложение (iOS + Android), где люди продают билеты, которые не смогут использовать, а те, кто не успел купить в кассе, покупают их.

## Запуск

```bash
npm install
npx expo start        # QR-код → Expo Go на телефоне
npx expo start --web  # в браузере
```

## Экраны

| Экран | Файл |
|---|---|
| Главная: город, поиск, категории, «Раскуплено в кассе», новые объявления | `src/screens/HomeScreen.tsx` |
| Афиша / категория: фильтры, сортировка, «только с билетами» | `src/screens/CatalogScreen.tsx` |
| Событие: инфо, цена в кассе, все предложения, «У меня есть билет — продать» | `src/screens/EventScreen.tsx` |
| Объявление: сектор/ряд/места, наценка к номиналу, продавец, безопасная сделка | `src/screens/ListingScreen.tsx` |
| Оформление (Payme / Click / Uzcard-Humo / Visa) и экран успеха | `src/screens/CheckoutScreen.tsx` |
| Продать билет: событие → данные → цена → фото билета → публикация (и редактирование) | `src/screens/SellScreen.tsx` |
| Кабинет, мои объявления, мои покупки, избранное, вход по SMS | `src/screens/ProfileScreens.tsx` |

Категории: концерты, театр, спорт, стендап, детям, фестивали, выставки, кино. Площадки: Humo Arena, Дворец дружбы народов, Panorama, ГАБТ им. Навои и др. Справочники и демо-данные — `src/data.ts`, состояние — `src/store.tsx` (в памяти).

## Правила площадки (в коде)

- Наценка не выше +50% к номиналу (`MAX_MARKUP`).
- Сервисный сбор 7% платит покупатель (`SERVICE_FEE`), продавец получает свою цену.
- Безопасная сделка: деньги замораживаются и уходят продавцу только после передачи билета.
- Фото/скрин билета обязателен — его видит только модератор.
